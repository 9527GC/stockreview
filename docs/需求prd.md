# 股票交易复盘系统：当前功能与产品边界

核对日期：2026-10-25。本文描述当前仓库实现；历史方案见 superpowers 目录，不能将方案中的待办视为已上线功能。

## 产品目标

记录交易原因、执行过程、情绪和改进措施，结合持仓、资产与历史收益进行复盘。支持 A 股、港股和美股，证券原币种包括 CNY、HKD、USD。

## 当前功能

| 模块 | 当前能力 |
|------|----------|
| 账号 | 账号密码登录、注册接口、修改密码、退出登录；微信小程序扫码登录、绑定与解绑 |
| 个人中心 | 昵称、头像、微信绑定状态维护 |
| 交易 | 买入卖出、修改和删除、手续费偏好、证券搜索与报价自动填充 |
| 资金 | 入金出金及记录列表，影响现金和本金 |
| 资产 | 总资产、现金、持仓市值、累计盈亏、今日盈亏 |
| 持仓 | 当前持仓与交易明细；历史清仓周期及各周期明细 |
| 复盘 | 按证券、日期、买卖方向筛选；情绪、交易逻辑、系统符合度、认知偏差、改进措施及新闻 |
| 公司行动 | 现金分红、拆分/合并、送股、转增、配股；新增、编辑、删除及历史重算 |
| 市场 | 大盘概览、个股行情、共享搜索、交易日历史大盘快照 |
| 收益 | 收益曲线、上证指数基准、收益日历、月度统计及估值质量 |

## 业务口径

- 账户现金、资产与本金以人民币汇总，外币按当前汇率折算；没有独立的原币现金账户和锁定汇率账本。
- 当前成本计算采用摊薄成本。买卖手续费进入资金和成本计算，出入金改变本金，不计为投资收益。
- 总资产 = 现金 + 持仓市值；累计盈亏 = 总资产 - 当前本金。
- 资产汇总先刷新估值，再更新并读取北京时间当天的 DailyProfit。今日盈亏不能简单累加持仓临时盈亏来替代。
- 收益曲线按区间内每日收益率复利计算；基准按请求区间的上证指数历史行情计算，缺失时返回 null。
- 收益日历读取 DailyRevenue，返回每日金额、每日收益率、估值质量及月度统计。月收益率使用月初本金作为分母。
- 历史持仓按独立清仓周期返回 cycleId，同一证券可能有多个周期。
- CorporateAction 参与份额、现金和历史重算；CompanyAction 用于持仓明细中的公司事项记录，两者是独立接口和集合。
- 补录交易、修改或删除影响份额的记录时校验历史序列，拒绝历史超卖。修改日期从新旧日期较早者开始重算。
- 行情无法取得时可使用缓存和降级数据；缺失值和 partial 质量标记应如实展示。

## 页面与流程

1. 登录后进入资产页，查看资产、持仓、收益曲线及日历。
2. 添加交易时搜索证券，确认价格、数量、手续费和北京时间，并填写复盘内容。
3. 资金转入转出后刷新资产；历史流水变更触发受影响日期之后的收益重算。
4. 持仓详情展示交易和公司事项；历史持仓按清仓周期展开。
5. 复盘列表支持筛选、编辑和删除交易；个人中心维护资料和微信绑定。

## 权限与验收边界

- 资产、交易、资金、公司行动和行情接口要求 Bearer Token，并按当前用户隔离业务数据。
- 微信扫码登录和绑定采用各自的会话及状态查询流程；真实扫码授权仍需微信客户端验证。
- 本地开发连接本机 MongoDB，生产使用阿里云实例；只有本地与生产两个环境。
- 接口字段、路径和错误约束以 [API 文档](apidoc.md) 及已注册路由为准。
- 默认后端、前端和小程序回归用于验证当前功能；tests/specifications 中保留的待实现规格不计为通过。

## 尚未实现或不作当前承诺

锁定历史汇率、分币种现金账户、标准加权成本、业务数据重置脚本，以及风险指标、收益来源分析、策略统计和提醒功能。历史设计稿中的分区存储、更多基准或未登录查看个人收益不代表当前能力。
